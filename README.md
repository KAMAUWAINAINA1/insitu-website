# Insitu Resources Advisory Ltd — Website

Static multi-page website for the mining and advisory company. Plain HTML and CSS, no build step.

## Pages
- `index.html` — Home (two pillars overview)
- `mining.html` — Mining pillar
- `advisory.html` — Advisory pillar
- `about.html` — About, principles, leadership
- `contact.html` — Contact details and form
- `styles.css` — shared styles for every page
- `assets/` — images (logo, leadership photo)

## Editing
Open any `.html` file and edit the text directly. Shared look lives in `styles.css`.
Placeholder blocks (dashed boxes) mark where real content goes later — portfolio projects, team profiles.

## Contact form
The form is a front-end demo and does not send yet. To receive messages, connect it to a
form service (Formspree, Getform) or your own backend.

## Deploy (GitHub Pages)
Push to the `main` branch, then in the repo: Settings > Pages > Deploy from a branch > main > / (root).
